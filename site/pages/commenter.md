<p class="lead">Ce texte est un avant-projet. Il est fait pour être discuté, corrigé et amélioré, article par article.</p>

## <span class="kicker">01</span>Commenter un article

Sous chaque article, le bouton **Commenter** ouvre le fil de discussion de cet article. Vous pouvez y poser une question, signaler une incohérence ou défendre une autre formulation.

Les commentaires sont hébergés sur GitHub Discussions : il faut un compte GitHub, gratuit, pour écrire. La lecture est ouverte à tous.

<p><a class="rp-btn rp-btn--primary" href="/texte/">Lire le texte et commenter</a></p>

## <span class="kicker">02</span>Proposer une modification

Le texte est conservé sur GitHub, un fichier par titre. Pour proposer une nouvelle rédaction :

1. ouvrez le fichier du titre concerné dans le [dépôt du projet](https://github.com/{{repo}}/tree/main/constitution) ;
2. cliquez sur le crayon pour le modifier, directement dans votre navigateur ;
3. décrivez votre proposition et envoyez-la : elle devient une « pull request », que l’équipe et les autres contributeurs peuvent relire, discuter, puis intégrer ou non.

Chaque modification intégrée reste visible dans l’historique du texte.

## <span class="kicker">03</span>Ouvrir un débat de fond

Pour une question qui dépasse un article (un choix de principe, une articulation entre plusieurs titres), ouvrez une [discussion](https://github.com/{{repo}}/discussions) ou un [ticket](https://github.com/{{repo}}/issues).

## <span class="kicker">04</span>Règles de la discussion

- Discutez le texte, pas les personnes.
- Une idée par commentaire, avec l’article concerné.
- Proposez une rédaction quand vous critiquez une formulation.
- Les messages injurieux, discriminatoires, publicitaires ou hors sujet sont retirés.
